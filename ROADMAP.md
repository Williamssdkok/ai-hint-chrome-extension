# AI Hint Roadmap (6 months)

## Phase 1 — Product clarity and onboarding
- Improve onboarding flow for first-time users
- Clarify the difference between local and Pro mode
- Improve the settings page and default user experience
- Polish the first-run guide and installation help
- Add better error handling for local AI availability

## Phase 2 — Retention and daily workflows
- Add smarter answer presets and custom templates
- Improve answer history search and filters
- Add favorites / pinning improvements
- Add category-based answering (explain, rewrite, summarize, fix)
- Improve follow-up action quality

## Phase 3 — Developer workflow
- Better code explanation and code-fix UX
- More precise coding-related answer modes
- Support smarter in-page code actions
- Improve technical context and snippet handling

## Phase 4 — Learning and research
- Add lesson-style explanation mode
- Support lightweight flashcards from selected text
- Add quick quiz generation
- Improve study-oriented answer styles
- Add highlight-based reading support

## Phase 5 — Growth and monetization
- Launch Pro tier
- Add premium workflow templates
- Add usage limits or higher-tier plans
- Improve marketing and landing page
- Build Chrome Web Store listing and search visibility

## Phase 6 — Stability and polish
- Improve accessibility
- Improve localization
- Improve security and privacy flows
- Add better analytics-free product instrumentation
- Refine UX polish and micro-interactions
