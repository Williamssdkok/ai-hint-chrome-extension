# AI Hint Lite

AI Hint Lite answers questions about selected text with Chrome's built-in on-device AI. It has no Pro mode, API-key field, provider code, or optional network permissions.

Pick Ordinary, Study, Code, or Translate in the popup or settings. Adjust answer length independently with Quick, Smart, or Deep.

## Install

1. Download `ai-hint-lite-1.3.1.zip` from the GitHub Actions package artifact.
2. Unzip it into its own folder.
3. Open `chrome://extensions`, enable **Developer mode**, and select **Load unpacked**.
4. Select the unzipped AI Hint Lite folder. A short welcome page opens after installation.
5. Select text on a regular web page and press `Ctrl+Shift+Space`.

AI Hint Lite requires Chrome 138 or newer and a device that supports Chrome's built-in AI. Chrome may need to download its local model before the first answer. If the model is unavailable, the extension explains that; it does not fall back to a cloud provider.

Choose a response style (Ordinary, Study, Code, or Translate), a response length, bubble auto-close time, and whether to show follow-up buttons. Settings and the offline game's high score stay in extension-local storage.
