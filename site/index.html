How it works

  • Select any text on a web page.
  • Press the shortcut or trigger the extension.
  • AI Hint reads the selection in context.
  • Get an answer next to the text or in-place in editable fields.
  • Use follow-up actions like explain, rewrite, compare, shorten, or translate.

Local mode by default

Use Chrome's built-in AI without needing an API key or cloud setup.

Optional Pro mode

Connect OpenAI, Gemini, Claude, DeepSeek, or Yandex using your own API key.

Install from source

  1. Download or clone the repository.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Click Load unpacked.
  5. Select the project folder containing manifest.json.
  6. Pin AI Hint from the Chrome toolbar.
